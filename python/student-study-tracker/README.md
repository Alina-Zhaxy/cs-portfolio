
# Student Study Tracker

A beginner-friendly Python CLI application for tracking study sessions and analyzing time spent on different subjects.

## Features

- Record study sessions
- Validate user input
- View recorded sessions
- Calculate total study time
- Summarize time spent per subject

## Technologies

- Python 3
- Lists and dictionaries
- Functions and loops
- Exception handling

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Run the following command:

   python main.py

## Future Improvements

- Save sessions to a CSV file
- Add dates and weekly statistics
- Visualize study patterns
- Store data in an SQL database
